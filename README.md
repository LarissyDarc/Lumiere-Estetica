# Lumière — Estética & Bem-estar

Landing page responsiva desenvolvida em React + Vite para um salão de estética.

## Rodar localmente

```bash
npm install
npm run dev
```

## Publicar no GitHub Pages

1. Envie este projeto para um repositório no GitHub, usando a branch `main`.
2. No repositório, abra **Settings → Pages**.
3. Em **Build and deployment**, selecione **GitHub Actions**.
4. Faça um novo push para `main`. O workflow incluído compila e publica automaticamente.

O endereço publicado será exibido ao fim da execução em **Actions**.
