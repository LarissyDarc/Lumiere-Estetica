## ▶️ Como Executar

```bash
npm install
npm run dev
```

## 🌐 Publicar no GitHub Pages

1. Envie o projeto para um repositório no GitHub, usando a branch `main`.
2. Acesse **Settings → Pages**.
3. Em **Build and deployment**, selecione **GitHub Actions**.
4. Faça um novo push para `main` para iniciar a publicação automática.
5. Consulte a aba **Actions** para verificar o resultado e acessar o endereço publicado.
